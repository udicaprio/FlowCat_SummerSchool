# Machine Learning for Process Intensification

## 🧪 Workshop overview

The workshop is designed for participants from chemical engineering, process engineering, and related scientific disciplines. No previous experience with Python, Jupyter notebooks, Google Colab, or machine-learning libraries is assumed.

The exercises use short explanations and guided coding steps. They are suitable for instructor-led delivery and sufficiently self-contained for later independent study.

## 🔍 What you will learn

**Python essentials:** Define variables, perform calculations, work with lists and arrays, use conditional statements and loops, and write simple functions.

**Process-data analysis:** Load tabular data, inspect and filter observations, calculate descriptive statistics, and construct plots with meaningful engineering labels and units.

**Machine-learning workflow:** Define inputs and outputs, separate training and test data, prevent information leakage, standardize variables, train a neural network, and evaluate predictions on unseen observations.

**Surrogate-based process design:** Interpret model errors and parity plots, check physical plausibility, and combine a trained surrogate with differential evolution to investigate promising process conditions.

## 🚀 Run the exercises in Google Colab

All notebooks are designed to run in [Google Colab](https://colab.research.google.com/) without a local Python installation.

1. Download this repository using **Code → Download ZIP** and extract the downloaded archive.
2. Open Google Colab and upload the workbook for the exercise you want to complete.
3. Open the **Files** panel in Colab and upload the CSV dataset from the same exercise folder.
4. Run the notebook cells from top to bottom, completing each marked task when instructed.
5. Consult the solution notebook after attempting the workbook tasks.

Each exercise is provided in two notebook versions:

- 📝 **Workbook:** explanations, guided tasks, suggestions, and incomplete code for participants to complete.
- ✅ **Solution:** complete code and expected results for checking the completed work.

## 🏫 Further open learning material

- [Chemical Reaction Engineering in Python](https://github.com/FiammettaC/Chemical-Reaction-Engineering-in-Python): an introductory collection covering Python syntax, stoichiometry, ordinary differential equations, visualization, and data analysis for reaction engineering.
- [Python meets Chemical Reaction Engineering](https://github.com/udicaprio/Python-meets-Chemical-Reaction-Engineering): hands-on Python and machine-learning code for chemical reaction-engineering applications.
- [KU Leuven ChemML workshop](https://gitlab.kuleuven.be/creas/vermeiregroup/cheml): hands-on material introducing chemical engineers to machine-learning fundamentals through process-modelling and property-prediction applications.
- [Machine Learning in Chemical Engineering](https://edgarsmdn.github.io/MLCE_book/intro.html): an extensive open resource on machine-learning methods and chemical-engineering applications.
